# 1.3 — Radio & the Blindfold Test

Two ways to listen without choosing a record: stations that keep playing and tell you why each track is there, and a
game that plays a clip and asks what you're hearing. Both run on data the app already has. The plumbing they need
(every named track resolved ahead of time) also makes era pages load instantly and is what 1.4 builds on.

(The game's name is an open decision; see the roadmap README. This file says Blindfold Test.)

## What people get

- **Stations**: one per era, one per decade, one per instrument, plus **The Long Way** (130 years in order, from
  ragtime to now) and, with the passport, **New to You**.
- **Why this track**: the player shows a line about what's playing and links to its record, artist and era.
- **The Blindfold Test**: rounds of ten clips. Which era? Who's playing? Which came first? The cover stays hidden
  until you answer; the reveal tells you what it was and why it matters.
- Era pages' Essential Tracks appear at once instead of resolving one by one.
- The iPhone's first tab becomes **Discover**.

## Data

### `tracks.json` (new, generated)

Every track the data names, resolved once to its Apple Music song. Today these are looked up live, one at a time, at
about 20 a minute (`ITunes.track(_:artist:)`, with a staggered delay per row in `EssentialTrackRow`).

The pool:

| From | Count now |
|---|---|
| `era.essentialTracks` | 98 |
| `album.highlights` × the album's artist | 262 |
| `artist.signatureTracks` | 273 |

455 after duplicates, growing with the catalogue. Keyed by the ID `TrackRef` already has (`"artist|title"`):

```json
{
  "Miles Davis|So What": {
    "trackId": 0, "name": "So What", "artistName": "Miles Davis", "albumName": "Kind of Blue",
    "collectionId": 0, "artwork": "https://…/100x100bb.jpg", "preview": "https://…", "url": "https://music.apple.com/…",
    "durationMillis": 0, "album": "kind-of-blue", "era": "modal", "year": 1959
  }
}
```

The first part is exactly `CatalogTrack`, so the app decodes it as one. `album`, `era` and `year` tie the track back to
the curated data: `album` when it's a highlight or its `collectionId` matches `catalog.json`; `era` from the era list
or the album; `year` from the ref or the album.

`scripts/build-tracks.py` works like `build-catalog.py`: only looks up what's missing, 3.1 seconds apart, saves as it
goes, prints misses. Scoring is the Swift scoring ported (title match, artist match, penalties for karaoke and
tributes), plus two rules the live lookup can't apply: prefer the version on the album in `catalog.json`, and prefer
the earliest release over a live remake. A first full run is about 25 minutes. Misses stay unresolved and are simply
not in stations.

### `tracklists.json` (new, generated)

`build-catalog.py` also saves each album's tracks (one lookup per album, 88 requests). Album pages open with their
tracklist already there, the validator can check 1.1's `only`/`except` titles, and 1.4 can find tunes on records.

### Preview links

Preview URLs are stored in the bundle and Apple can change them. The app treats a failed preview as a cache miss:
look the track up again by `trackId` (`/lookup?id=`), cache the fresh link in `DiskCache`, play. The existing disk
cache has the same exposure today, so this is a fix as well as a precaution.

### Validator

Every key in `tracks.json` is a track the data still names; `album` and `era` resolve; a report of unresolved tracks
per era, so a thin station is visible before release.

## Shared code

### `Shared/Model/Stations.swift`

```swift
struct Station: Identifiable, Hashable {
    enum Kind: Hashable { case era(String), decade(Int), instrument(String), longWay, newToYou }
    let kind: Kind
    var id: String        // "era-bebop", "decade-1950", "instrument-saxophone", "long-way", "new-to-you"
    var title: String     // "Bebop Radio", "1959 and Around", "Tenor & Alto", "The Long Way"
    var tint: Color
}

struct Programmer {
    func pool(for station: Station, library: JazzLibrary) -> [StationTrack]
    func sequence(_ pool: [StationTrack], seed: UInt64, avoiding recent: Set<Int>) -> [StationTrack]
    func reason(for track: StationTrack, library: JazzLibrary) -> String
}
```

- **Pool**: era → tracks tagged with it; decade → by year; instrument → tracks whose artist (or, with 1.1, any credited
  player on its album) plays it; The Long Way → everything, in year order; New to You → tracks from albums the
  passport says are unheard, weighted toward eras with the least ink.
- **Sequence**: a seeded shuffle (so tests are stable) with three rules: never the same artist twice in a row, never
  the same album within five tracks, and start with one of the era's essential tracks so a station opens with
  something unmistakable. The Long Way isn't shuffled; it picks two or three tracks per era in order, a different
  selection each time.
- **Reason**: built from what the data already says, in order of preference: the album's `why` (first sentence), the
  milestone of that year, the artist's blurb. Prefixed by how the track got here: "From *Kind of Blue* (1959)".

### Player

- `PlayContext.station(String)`.
- `playStation(_ tracks: [CatalogTrack], context:)`: with Apple Music, queue the first 25 and append the next batch
  when five remain, so a station doesn't end. With previews, the existing preview queue, refilled the same way.
  Appending to a running MusicKit queue is to be confirmed on the Mac, where MusicKit has gaps this project has
  already met (it reports no audio variant there); the fallback is replacing the queue between tracks.
- `nowPlayingRef`: the `StationTrack` for the current song, found by song ID, so views can show the reason.
- **Blind mode** for the game: `playBlind(_ track:)` plays the 30-second preview and publishes nothing identifying.
  `current` holds a placeholder title; on iPhone, `updateNowPlayingInfo()` must not put the real title, artist or
  artwork on the lock screen or in Control Center, which would give the answer away. Blind clips are always previews,
  with or without a subscription: they're the same for everyone, they start on a recognisable passage, and they don't
  scrobble.

### `Shared/Model/Blindfold.swift`

```swift
struct Question { enum Kind { case era, artist, instrument, whichFirst }
                  let kind: Kind; let clip: StationTrack; let second: StationTrack?
                  let choices: [Choice]; let answer: Choice.ID }
struct RoundMaker { func round(level: Level, library: JazzLibrary, seed: UInt64, focus: String?) -> [Question] }
```

- **Which era?** Four choices. Easy: eras far apart in time. Hard: neighbours (bebop / hard bop / cool / modal).
- **Who's playing?** Four artists. Easy: different instruments and eras. Hard: same instrument, same era.
- **What's the lead instrument?** Only from tracks whose artist has a single clear instrument.
- **Which came first?** Two clips, played one after the other.

A round is ten questions, mixed kinds, no artist twice. Every question's clip must have a preview. `focus` limits a
round to one era ("Test me on swing"). Scoring: one point each, a streak count, no timer. Results are stored in the
passport (once 1.2 exists) as right/total per era, which gives the Passport page "Your ear knows hard bop; swing needs
work" with a button to that station.

## Mac

- **Sidebar**: a **Listen** section with **Radio** and **Blindfold Test**. **Timeline** is renamed **Discover**.
- **`RadioView`** (new): a wall of stations as record centre labels (`StationLabel`: a circle in the station's tint,
  the name set on a curve, a spindle hole; it rotates while that station plays). Grouped: The Long Way and New to You
  large at the top, then eras, decades, instruments.
- **`HomeView`**: a **Radio** row under the hero with six stations and *See all*.
- **`EraDetailView`, `DecadeDetailView`**: a *Play Radio* button beside the title. The artists page's instrument
  filter gets one too.
- **`NowPlayingBar`**: when a station is playing, a second line with the reason and three links (record, artist, era),
  and the station's label as the artwork badge.
- **`BlindfoldView`** (new): level and focus pickers, then the round. The clip plays under a blurred typographic
  sleeve with a large question mark; four answer buttons; on answering, the sleeve turns over to the real cover with
  the reason, a link to the record, and *Save*. End of round: score, the ones you missed, *Play these on the radio*.
  Keyboard: 1–4 to answer, space to replay, return for next.
- **`EssentialTrackRow`**: reads `tracks.json` first; the live lookup remains for anything not in it.

## Tests

- Sequencing: no artist back to back and no album within five, across 1,000 seeds; the opener is an essential track;
  The Long Way is in order.
- Pools: every era station has at least 12 tracks with the bundled data (a data check as much as a code check).
- `reason` is never empty.
- Round maker: four distinct choices, the answer among them, ten questions, no repeated artist, hard distractors
  really are neighbours.
- Preview refresh: a 404 on a preview triggers one re-lookup, not a loop.

## Risks

- **Thin stations.** Soul jazz and spiritual jazz have three artists each today. The validator's per-era count shows
  it; the catalogue work ([catalog.md](catalog.md)) is the fix, and a station with fewer than 12 tracks is hidden.
- **Wrong matches** in `tracks.json` (a live remake, a different artist's cover) are worse in a quiz than on a page.
  The script prints every match for a read-through, and a `"skip": true` flag keeps a track out of the game.
- **Preview offsets** are Apple's choice. Some clips start on a drum intro that says nothing. The same `skip` flag
  handles those, found by playing rounds, which needs your ears.
- **Leaking the answer** through the lock screen, AirPlay metadata or the Mac's Now Playing widget. Blind mode covers
  it and has a test on what gets published.

## Done when

The common checklist, plus: Bebop Radio plays for an hour without repeating an artist back to back or stopping; a
round of ten can be played on a locked-screen iPhone with AirPods without the answer appearing anywhere; an era page
shows its tracks with artwork on first paint.
